# Web application

Run workspace commands from the repository root. See [the root README](../../README.md) for configuration and deployment, and [CONTRIBUTING.md](../../CONTRIBUTING.md) for development, testing, and architecture.

`src/server/gateway.ts` runs in the HTTP server; API handlers and database access run in the backend worker, and exports run in a separate export worker. Browser HTTP clients live in `src/client/api` and the DuckDB runtime in `src/client/analytics`. `src/routes` belongs to TanStack Start; its route tree is generated by the router plugin and is not checked in. Shared contracts live in `packages/contracts`. Product analytics execute in browser DuckDB-WASM over an `events` view combining monthly S3 Parquet (completed UTC days) with a local table imported from the gzip-compressed SQLite snapshot API. The response pins both sources to a single read transaction; the browser replaces its table and view together. Today stays in SQLite, monthly history advances daily, and dirty or unpublished history temporarily falls back to SQLite.
