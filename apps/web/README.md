# Web application

Run workspace commands from the repository root. See [the root README](../../README.md) for development, production, configuration, testing, and architecture.

`src/server` executes only in a Bun worker. `src/routes` belongs to TanStack Start; its route tree is generated by the router plugin and is not checked in. Shared contracts live in `packages/contracts`. Product analytics execute in browser DuckDB-WASM over revisioned Parquet snapshots.
