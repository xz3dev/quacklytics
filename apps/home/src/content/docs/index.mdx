## How it works

Quacklytics stores recent events in **SQLite** on your server and moves history into **Parquet** files in an S3 bucket. When you open a dashboard, your browser loads that data into **DuckDB** and runs the queries itself. The server stays small and cheap, and charts stay fast.

## Up and running in four steps

<Steps>

1. **Clone the repository.**

    ```sh
    git clone https://github.com/xz3dev/quacklytics.git
    cd quacklytics
    ```

2. **Start the server** locally with the [Local Setup](/start-here/local/), or [deploy to production](/start-here/production/).

    ```sh
    docker compose up --build
    ```

3. **Create a project** at `http://localhost:3000`, then copy its ingestion key from the **Ingestion** page.

4. **Send your first event** with the [TypeScript client](/guides/send-data/) or plain HTTP.

    ```ts
    await client.track("signup", { plan: "pro" });
    ```

</Steps>
