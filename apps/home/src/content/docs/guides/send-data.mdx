## Sending events via HTTPs

The **AppendEvent** endpoint allows you to send one event or a batch of events to the server for processing. The API key identifies the project.

### Endpoint URL

```
POST /api/ingest
```

### Request Format

**Request Headers**

- **Content-Type:** `application/json`
- **X-API-KEY:** `your-api-key` - Create a new api-key via the project settings.

**Request Body**

The endpoint accepts an object with a UUID `requestId` and an `events` array (1–1000 events, at most 2 MB). Every event needs a UUID `id`. Keep both IDs unchanged when retrying. Reusing an ID with different content returns 409 and rolls back the entire batch. Event fields:

- **eventType**: The type of event (e.g., `"user_signup"`).
- **sessionId**: Optional session identifier for pseudo-anonymous events.
- **personId**: Optional person identifier. Sending both `sessionId` and `personId` upgrades the session to that person.
- **timestamp**: The time of the event occurring in ISO 8601 format.
- **properties**: A map of additional properties. This is stored as JSON and can be queried.
- **personProperties**: Optional person properties. The latest event timestamp wins per property, with event ID resolving equal timestamps.

### Example

```json
{
  "requestId": "bb7b720a-0d30-4f6b-a159-910a56b70c51",
  "events": [
  {
    "id": "24fc73e5-aa9b-4c28-bc3f-3bd02a5bc0c3",
    "eventType": "user_signup",
    "sessionId": "session_abc",
    "personId": "person_123",
    "timestamp": "2025-02-23T10:00:00Z",
    "properties": {
      "plan": "premium",
      "referrer": "google"
    },
    "personProperties": {
      "email": "test@example.com"
    }
  }
  ]
}
```

## Sending events via the TypeScript client

The client automatically sends a `$pageview` event when it is created in a browser. Disable that with `autoTrackPageviews: false` and call `trackPageview()` manually when you want to control timing, for example after consent has been resolved.

```ts
import { createClient } from "@quacklytics/client";
import { enableClickAutotracking } from "@quacklytics/client/autotrack";

const client = createClient({
  apiKey: "your-api-key",
  hostname: "localhost",
  port: 3000,
  autoTrackPageviews: false,
});

await client.trackPageview();

enableClickAutotracking({ client }); // emits $click events
```

Browser context such as user agent, browser name and version, operating system, device type, device model, language, timezone, viewport, and current page URL is added to every event's `properties`.

Browser ingestion requires the browser origin in project settings. Keys are shown in full only when created. The tracker generates IDs and retries network/5xx/429 failures using the same payload. A successful response acknowledges a committed SQLite WAL/FULL transaction.
